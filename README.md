## نقاط الضعف التي تم إصلاحها

### 1) معرض الصور

| قبل | بعد |
|---|---|
| ❌ chevrons فقط، لا swipe | ✅ swipe أصلي بـ `scroll-snap` + touch handlers |
| ❌ counter كبير في الأسفل وسط | ✅ counter صغير في الزاوية + maximize button |
| ❌ لا dot indicators | ✅ dots متحركة (الحالي w-6، الباقي w-1.5) |
| ❌ chevrons دائماً ظاهرة | ✅ تظهر على hover فقط (ديسكتوب) - أنظف |
| ❌ thumbnails على الموبايل تأخذ مساحة | ✅ مخفية على الموبايل، تظهر sm+ فقط |
| ❌ keyboard navigation فقط في lightbox | ✅ في lightbox + مع تنقل تلقائي |

### 2) القسم العلوي

| قبل | بعد |
|---|---|
| السعر فوق على اليسار - يُقرأ آخراً | شريط brand كامل بالسعر بـ 3xl + "السعر" caption |
| العنوان أكبر من السعر بصرياً | السعر هو الأكبر = القرار الأهم |
| التصنيف + "مميز" + "معتمد" مبعثرين | تصنيف + شارة "مميز" مرتبتان عمودياً يمين السعر |
| المواصفات الـ 4 في rounded squares | تقسيم خلوي بـ divide-x مع أيقونات brand |

### 3) أزرار التواصل (الأهم)

**قبل:** الأزرار في الـ sidebar اليميني = على الجوال تنزل لآخر الصفحة، المستخدم لا يصل إليها.

**بعد:**
- **Sticky CTA bar على الموبايل** يبقى دائماً ظاهراً (يختفي عند scroll للأسفل، يظهر عند الأعلى)
- 3 أزرار: مراسلة (icon) + اتصال (icon) + **واتساب بارز** (يأخذ المساحة)
- على الديسكتوب: sidebar يبقى مع `sticky top-24`

### 4) معلومات الإعلان

| قبل | بعد |
|---|---|
| كل الأقسام في كرت واحد ضخم (description + features + actions) | كل قسم في كرت منفصل = مسح بصري أسرع |
| المميزات والعيوب بـ bullet points بسيطة | أيقونات ملوّنة (✓ في دائرة خضراء، ! في دائرة وردية) |
| المواصفات الإضافية تحت المميزات | في كرت منفصل بعد الوصف |

### 5) بطاقة البائع

**قبل:** مجرد link مع صورة + اسم + city + rating + "عرض صفحة التاجر".

**بعد - مكوّن مخصص `SellerCard`:**
- صورة 56×56 بـ ring brand
- اسم + شارة ShieldCheck (لو ≥ 3 إعلانات = موثَّق)
- اسم النشاط التجاري + المدينة في سطر فرعي
- **شريط إحصائيات 3 أعمدة**: التقييم / المتابعون / عدد الإعلانات
- chevron يشير لصفحة التاجر

→ الثقة البصرية أقوى بكثير - بائع حقيقي بأرقام حقيقية.

### 6) التفاعل

استخدام `ListingActionsBar` الموجود (تم تحسينه في مراحل سابقة):
- نُقل إلى كرت منفصل أصغر
- لايك / تعليق / مشاركة / مفضلة بنفس النمط الأيقوني النظيف

### 7) تجربة الجوال

| قبل | بعد |
|---|---|
| `pb-28` ثابت على كل الصفحات | `pb-32` على هذه الصفحة فقط (مساحة للـ sticky CTA) |
| الـ sidebar يدفع للأسفل = المعلومات المهمة بعيدة | بطاقة البائع في العمود الرئيسي على الموبايل، sidebar للديسكتوب فقط |
| لا swipe بين الصور | swipe أصلي + touch handlers |
| الأزرار تحتاج scroll للوصول | Sticky CTA دائماً ظاهر |
